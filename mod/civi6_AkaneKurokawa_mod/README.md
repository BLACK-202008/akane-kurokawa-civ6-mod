# 《我推的孩子》黑川茜：文明6 自定义文明模组

为《文明6》制作的自定义文明，新增文明 LALALAI 和领袖黑川茜。玩法围绕特色区域 LALALAI 剧团展开：剧团和周围的专业区域互相提供相邻加成，把文化布局延伸到科技、信仰、生产、伟人点和战斗。

## 基本信息

- 题材：《我推的孩子》中的黑川茜
- 文明：LALALAI
- 领袖：黑川茜
- 玩法关键词：区域联动、剧院强化、阶段爆发、角色切换
- 适用版本：只适配风云变幻规则（需要迭起兴衰和风云变幻），基础游戏和迭起兴衰规则不支持

整体思路是用同一套城市布局，在不同阶段换重心：

- 前中期：LALALAI 剧团配合学院、商业中心、圣地、军营，多区域联动。
- 中后期：用话剧演员把重要城市变成高联动的核心城，开始爆发。
- 任何时候：根据局势切换星野爱、鞘姬、星野露比三种角色。

## 文明能力与特色内容

### 1. 特色区域：LALALAI 剧团

替代剧院广场。

- 基础 +1 文化、+2 宜居度。
- 保留风云变幻规则下剧院广场原有的文化相邻加成，来源包括奇观、相邻区域、政府广场和娱乐区域。
- 每相邻 1 个市中心：+1 文化、+2 金币。
- 每相邻 1 个奇观：+2 文化、+2 金币。
- 每相邻 1 个娱乐中心、水上乐园或它们的替代区域：+2 文化。
- 专家额外 +2 食物、+1 生产力。

相邻的专业区域也会从剧团得到额外的相邻加成：

| 相邻区域 | 额外相邻加成 |
| --- | --- |
| 学院 | +1 科技 |
| 商业中心 | +2 金币 |
| 港口 | +2 金币 |
| 娱乐中心 | +2 生产力 |
| 水上乐园 | +2 生产力 |
| 军营 | +1 生产力 |
| 工业区 | +1 生产力 |
| 圣地 | +1 信仰 |

规划城市时以剧团为中心：它自己吃市中心和奇观的相邻加成，也给周边的专业区域加相邻产出。

### 2. 文明特性：多面舞台术

与 LALALAI 剧团相邻的区域，其中的标准建筑产出 +50%：

| 区域 | 受影响的建筑 |
| --- | --- |
| 学院 | 图书馆、大学、研究实验室 |
| 商业中心 | 市场、银行、证券交易所 |
| 港口 | 灯塔、造船厂、海港 |
| 军营 | 兵营、马厩、军械库、军事学院 |
| 工业区 | 工作坊、工厂、电子厂、燃煤发电厂、燃油发电厂、核电站 |
| 圣地 | 神社、寺庙 |

与剧团相邻的以下区域还会额外提供伟人点：

| 区域 | 伟人点 |
| --- | --- |
| 学院 | 大科学家 |
| 商业中心 | 大商人 |
| 港口 | 大海军统帅 |
| 军营 | 大将军 |
| 圣地 | 大预言家 |

这些伟人点会随区域里的建筑继续增加。例如学院本身加点，图书馆、大学、研究实验室建成后再各自加点；军营的兵营或马厩、军械库、军事学院同样会继续提高大将军点。

布好城之后，一座核心城的建筑产出、伟人点和相邻加成会一起上涨。

### 3. 特色单位：话剧演员

黑川茜专属的平民单位。它不使用原版摇滚乐队的音乐会、升级链和随机晋升，只用于本模组的舞台演出。

- 可以用信仰购买。
- 有 3 次演出机会，每次演出消耗 1 次。
- 只能在己方城市的 LALALAI 剧团上演出，每座城市只能演出 1 次。
- 最后一次演出后单位移除。

演出后，这座城市获得以下永久效果：

- 剧团和与它相邻的专业区域，相邻产出永久翻倍。翻倍对象包括风云变幻规则下的原版相邻加成和剧团提供的额外相邻加成。
  - 剧团自身：来自市中心的 +1 文化、来自奇观的 +2 文化、来自娱乐中心或水上乐园（含替代区域）的 +2 文化、来自政府广场的 +1 文化，以及来自市中心、奇观的 +2 金币等，都会翻倍。
  - 相邻的学院、商业中心、港口、娱乐中心、水上乐园、军营、工业区、圣地：现有的相邻产出整体翻倍。
- 城里的剧院类建筑各额外 +1 文化：古罗马剧场、美术馆、考古博物馆、广播中心。
- 城里每有 1 座上述建筑，旅游业绩 +20%。
- 给全国叠一层艺术繁荣，见下一节。

这些效果挂在城市上，永久有效。之后在这座城里新建的相邻专业区域，也会获得同样的翻倍。话剧演员的用法就是挑一座核心城，把它变成高联动的城市。

### 4. 全国效果：艺术繁荣

每次舞台演出给全国叠一层艺术繁荣。

- 每层：食物、生产力、金币、科技、文化、信仰各 +8%。
- 所有层共用一个剩余回合数。每次演出叠一层，并把剩余回合数延长一段，但不超过上限；剩余回合数归零时，所有层一起清除。
- 读档后会恢复。

| 游戏速度 | 每次演出延长 | 剩余回合上限 |
| --- | --- | --- |
| 联机 | 12 | 50 |
| 快速 | 17 | 70 |
| 标准 | 25 | 100 |
| 史诗 | 37 | 150 |
| 马拉松 | 50 | 200 |

越早开始叠层，全国产出越早被拉起来。

## 领袖：黑川茜

领袖特性“角色掌控者”包含两部分：始终生效的“推理大师”，以及可以切换的三种角色。推理大师提供稳定的科技底子，节奏靠角色切换来带。

### 推理大师（始终生效）

- 全国 +1 文化。
- 解锁数学后，科技 +10%。
- 解锁科学理论后，科技再 +10%。
- 每次伟人隐退时，额外获得 1 个随机尤里卡。

### 三种角色

#### 星野爱

定位：信仰经济、宗教对抗。

- 全国 +1 信仰。
- 大预言家点数 +1，每个圣地再 +1。
- 信仰 +30%。
- 所有宗教单位（包括审判官）在宗教战斗中 +10 战斗力。
- 用信仰购买单位或建筑时，返还本次所花信仰 80% 的金币。

#### 鞘姬

定位：文化推进、旅游、鼓舞。

- 全国 +1 文化。
- 大艺术家、大作家、大音乐家点数各 +1，每个 LALALAI 剧团再各 +1。
- 文化 +20%，旅游业绩 +30%。
- 每次招募伟人时，额外获得 1 个当前可研究市政的随机鼓舞。

#### 星野露比

定位：军事压制、快速扩军。

- 所有单位 +5 战斗力、+1 移动力。
- 全国 +1 生产力。
- 大将军点数 +1，每个军营再 +1。
- 每个军营额外 +1 生产力。
- 击败敌方单位时，获得相当于该单位 80% 成本的信仰。

### 角色切换

- 只能在自己的回合里切换。
- 切换后立即进入冷却，冷却结束前不能再切换。
- 切换成功后，在冷却时长的一半内，食物、生产力、金币、科技、文化、信仰各 +16%。

| 游戏速度 | 冷却回合 | +16% 持续回合 |
| --- | --- | --- |
| 联机 | 5 | 2 |
| 快速 | 7 | 3 |
| 标准 | 10 | 5 |
| 史诗 | 15 | 7 |
| 马拉松 | 20 | 10 |

## 技术结构

- `Data/`：文明、领袖、区域、单位、修正（Modifier）和条件（Requirement）等数据库定义。
- `Scripts/`：游戏逻辑。包括话剧演员的演出、艺术繁荣的叠层与到期、角色切换的冷却和 +16% 加成、星野爱的信仰返金、推理大师的随机尤里卡、鞘姬的随机鼓舞，以及演出后城市永久效果的挂载和读档恢复。
- `UI/`：顶栏的角色切换面板、单位面板上的演出按钮、生产面板的购买接入，以及相关的界面兼容处理。
- `Text/`：中英文文本。
- `Icons/`、`Textures/`、`ArtDefs/`：图标、美术资源和美术映射。

## 安装与测试

1. 把 `civi6_AkaneKurokawa_mod` 文件夹整个放进游戏的 `Mods` 目录，也可以用开发仓库 `dist/` 里的安装包。
2. 在模组菜单里启用本模组。
3. 用风云变幻规则新开一局，选择 LALALAI / 黑川茜。
4. 重点检查：
   - 切换角色后保存，反复读档：角色加成和临时 +16% 都不会叠加；+16% 到期后再读档，不会被重复扣掉。
   - 同样的建筑分别建在邻接和不邻接剧团的区域里：只有邻接的区域拿到 +50%。替代区域和跨城邻接也要测：学院挨着别的城市的剧团也算邻接，但学院所在的城市自己也要建有剧团。
   - 星野爱模式下用信仰购买单位、军团、军队和建筑：按实际花费返还 80% 金币。用金币购买、购买失败、用信仰赞助伟人都不返金。
   - 星野爱模式下信仰购买后，`Lua.log` 里没有报错，生产面板正常关闭。
   - 联机：双方看到的角色切换和返金结果一致；原生购买操作和它前后的两条脚本操作按顺序执行。

`Mods` 里只放运行文件和这份说明；`.git`、`dev`、`review`、`dist` 和源素材留在开发仓库。

自动回归测试在开发仓库本地的 `dev/tests/`，不随模组分发。

角色状态现在会记录哪些效果已经挂上、哪些已经清算。旧存档第一次加载时只登记现有效果，不会再挂一遍。旧版本没有记录实际叠加的次数，以前读档造成的重复加成或重复扣减没法可靠地撤回，验证数值请用新存档。

信仰返金的实现方式：生产面板调用原生购买函数时，前后各发一条脚本操作，把这一次购买单独标记出来，再用购买事件和实际扣掉的信仰来确认。如果其他模组也替换生产面板，需要保留对 `Akane_PurchaseSupport` 的调用，否则返金不会触发。
